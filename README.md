# 院内チャンネル 見本画面

待合室のテレビに映す「院内チャンネル」の見本です。検査の流れ、呼び出し番号、待ち時間、お知らせを1枚の画面で伝えます。

| 見本 | 開く |
|---|---|
| 待合室の画面 | https://yamaguchig5167-afk.github.io/sol8-innai-channel/ |
| 管理画面（受付スタッフ用） | https://yamaguchig5167-afk.github.io/sol8-innai-channel/admin.html |

## 画面に出るもの

- **案内（自動で切り替え）**　検査の流れ／前日のお食事／鎮静剤を使った日／次回のご予約／外来担当／待合室でのお願い
- **呼び出し番号**　診察室と内視鏡室の2列。番号が進むと枠が光ります
- **待ち時間の目安**　受付から5分きざみで変更
- **お知らせ**　画面の下を流れる文。大事なものは案内の1枚目に大きく表示
- **3つの言語**　日本語 → 繁體中文 → 日本語 → English の順に自動で切り替え
- **非常時の表示**　地震・火災のとき、全画面が避難の案内に切り替わります

## 管理画面でできること

受付で操作するのは次の4つだけです。右側に待合室の画面が映り、押した結果をその場で確かめられます。

1. お知らせを出す（60字まで・出す期限つき）
2. 休診を知らせる（初日と最終日を選ぶ。繁体字・英語の日付は自動）
3. 待ち時間の目安を変える
4. 非常時の表示に切り替える（押し間違いを防ぐため2回押し）

検査や病気の説明は、院長先生の確認を経てから差し替える運用です。

## 院名と色を変えて見る

アドレスの後ろに付けると、院名・色・切り替えの速さを変えられます。

| 付けるもの | 例 | 変わるところ |
|---|---|---|
| `?name=` | `?name=○○クリニック` | 左上の院名 |
| `&color=` | `&color=1F6B45` | 帯と見出しの色（6桁の色番号） |
| `&sec=` | `&sec=8` | 案内1枚を映す秒数（4秒以上・初期値12秒） |

## キーボードでの操作（待合室の画面）

| キー | 動き |
|---|---|
| `→` | 次の案内へ |
| `L` | 言語を切り替え |
| `N` | 呼び出し番号を進める |
| `E` | 非常時の表示を出す／戻す |
| `F` | 全画面 |

画面に触れるかマウスを動かすと、右下に同じ操作のボタンが4秒間出ます。

## 見本であることについて

- 院名・医師名・番号・休診日はすべて架空です。
- 検査や食事の文は見本です。実際の準備は、受診する医療機関の説明に従ってください。
- この見本では、管理画面の変更は同じ端末の中だけで画面に届きます。導入時は院ごとのIDで入り、待合室のすべての画面に届く形にします。
